流量分析部分

2025-11-3

流量包下载（免得想做流量分析的人需要去下载完整镜像浪费时间和流量）：

通过网盘分享的文件：流量包（来自原始镜像）.pcap
链接: https://pan.baidu.com/s/1a23BbJIucG2G9RHKu3IptA?pwd=z3iu 提取码: z3iu

流量分析

21、黑客攻击的目标路由器SSID为 （答案格式：请按实际值填写）​

laozhaoWIFI

首先看一下协议分级，确定流量包主要内容

包含IPV4流量、无线流量、data数据，结合题目问路由器，因此过滤wlan.fc.type_subtype == 0x05或0x08，这里过滤0x05

一共出现了don't panic、HUAWEI-4GLLRT、TP-LINK_5305、Huawei NovaX、TPGuest_5305、laozhaoWIFI

现在需要确定的是被攻击的目标服务器是哪一个

通常黑客在尝试连接目标路由器时，会发送 Association Request，其中包含目标 SSID。那么我们过滤wlan.fc.type_subtype == 0x00

发现结果均为laozhaoWIFI

22、黑客成功捕获了WIFI中WPA协议握手包，其中有效握手包组数为(完整握手为一组)​

4

直接过滤eapol，因为过滤 eapol 可以直接找到握手包

23、黑客爆破得出的WiFi密码为（提示：密码由小写英文字母和数字组成）（答案格式：abcd1234）​

password1110

后面发现黑客进入了后台，那么尝试通过http流搜索laozhaoWIFI，看看能不能看见密码配置

http contains "laozhaoWIFI"

24、黑客成功连接Wifi后，发现路由器操作系统为？（答案格式：请按实际值填写）​

ImmortalWrt

根据后面的题目知道进入了后台，通常后台的IP是192.168.1.1

我过滤的是tcp contains "192.168.1.1" && http contains "admin"

搜索name、server、title等

25、黑客对路由器后台进行爆破攻击，该路由器后台密码为​

password

过滤一下http的POST流，随便看看的时候发现了登录参数

过滤该参数

发现在密码为password时产生了cookie，并且后续也获得了返回值

26、黑客通过修改路由器设置，将被劫持的域名为（答案格式：www.xxx.com）​

www.qq.com

过滤http contains "domian"

27、黑客在路由器管理后台发现FTP服务配置，FTP登录密码为？（答案格式：请按实际值填写）​

mast

直接过滤ftp流量

28、黑客通过FTP上传了一个压缩包文件，该文件内容为（答案格式：请按实际值填写）​

code:123456789

过滤一下ftp-data contains "\x50\x4B\x03\x04"，发现有

原始数据导出

尝试爆破和伪加密先

29、黑客通过路由器执行shell脚本，反弹shell的监听端口为（答案格式：1）​

4445

一般都是nc，并且会有/bin/sh或者/bin/bash

先过滤tcp contains "nc "（注意有个空格）

30、黑客通过反弹shell成功控制目标路由器后，总共执行了多少条命令（答案格式：1)​

4

弹的用的是/bin/sh，过滤一下这个

蓝色的就是执行的内容，一共4条

同时也能确定操作系统ImmortalWrt、wifi是laozhao
