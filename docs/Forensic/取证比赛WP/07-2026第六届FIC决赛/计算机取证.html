10. 用上述密码解密嫌疑人窃取的外卖数据文件，其中address字段为沈阳市的用户数量为（无需去重或验证数据真实性）​

687

外卖数据文件在D:\mm下，这道题卡了很久，后面想了想按题目说“address字段”

既然是字段，那这个文件绝大概率是数据库文件，应该是被SQLCipher加密的

from pathlib import Path

import sqlcipher3

PASSWORD = "427d672e8b36c12343f8380628025677"
ENCRYPTED_DB = "外卖数据.dmp"
DECRYPTED_DB = "decrypted.sqlite"


def main():
    decrypted_path = Path(DECRYPTED_DB)
    if decrypted_path.exists():
        decrypted_path.unlink()

    con = sqlcipher3.connect(ENCRYPTED_DB)
    cur = con.cursor()
    cur.execute(f"PRAGMA key = '{PASSWORD}';")
    cur.execute("PRAGMA cipher_compatibility = 4;")
    cur.execute(f"ATTACH DATABASE '{DECRYPTED_DB}' AS plaintext KEY '';")
    cur.execute("SELECT sqlcipher_export('plaintext');")
    cur.execute("DETACH DATABASE plaintext;")
    con.close()

    print(f"done: {DECRYPTED_DB}")

if __name__ == "__main__":
    main()

然后注意，题目问address有多少个沈阳，不是region有多少个

这是使用 Nuitka onefile 打包出来的 Python 程序，会有直接可读的文本在程序中

例如这里就能确定IP是192.168.58.172

分析发现

\00u192.168.58.172
\00aC2_HOST
\00l\x8F\X4E
aC2_PORT

其中192.168.58.172为IP，那么\x8f\x4e为port，然后这里Python marshal/Nuitka 常量表里的一种变长整数编码，因此8f 4e 要按变长整数编码解析。

变长整数常见规则是：

  1. 每个字节低 7 位保存数值；
  2. 最高位表示后面是否还有字节；
  3. 如果最高位是 1，说明还要继续读下一个字节；
  4. 如果最高位是 0，说明整数结束。
0x8f = 1000 1111，最高位为 1，低 7 位是 0x0f
0x4e = 0100 1110，最高位为 0，低 7 位是 0x4e
计算得到
0x0f + (0x4e << 7)
= 15 + (78 * 128)
= 15 + 9984
= 9999

192.168.58.172:9999

接着在分析浏览器时发现路径

Google\Chrome\User Data\Default\Login Data
Microsoft\Edge\User Data\Default\Login Data

因此能获取2个浏览器密码。

从 RATClient.handle 附近可以确认的 action 有：

序号action功能解释
1ping心跳测试，返回 pong
2autostart_add添加开机自启动
3autostart_remove移除开机自启动
4clipboard_start开始监控剪贴板
5clipboard_stop停止监控剪贴板
6clipboard_dump导出剪贴板记录
7screenshot截图并返回图片数据
8browser_passwords收集浏览器登录数据
9exit退出或断开客户端

所以服务端可接收并处理的 action 指令共有9个
